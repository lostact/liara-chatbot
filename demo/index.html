آزمایش آنلاین دستیار مستندات لیارا

این صفحه برای ارزیابی ویجت چت‌بات و اتصال آن به سرویس‌های مستقرشده روی لیارا آماده شده است.

نکته:

آدرس API هنگام اجرای GitHub Actions به این صفحه اضافه می‌شود.

نمونه سوالات برای تست:

  • چطور برنامه Django رو روی لیارا مستقر کنم؟
  • نحوه اتصال به دیتابیس Postgres در لیارا
  • دستورات Liara CLI برای لاگین و دیپلوی
  • نحوه تنظیم متغیرهای محیطی
